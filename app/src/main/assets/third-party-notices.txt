TrueSample USB audio module
Source: https://github.com/devang-altf4/truesample-player/tree/cf23a00030cd2d27c91f667737f0ca9aa30256a4/usbaudio
License: Apache License 2.0 (licenses/Apache-2.0.txt)
The module's existing namespace and native integration are retained.
Modified by Evanna through 2026-11-04: PCM input validation, writer ownership,
callback-safe shutdown, clock/transport/volume verification, bounded USB
completion drain with SRC tail, separate PCM counters, two-transfer startup,
explicit planned/observed processing flags, float clipping checks, and tests.
Original license and attribution are retained.
The GPL TrueSample application and its decoder are not included.

FFmpeg 9.0.2
Copyright the FFmpeg developers. See licenses/FFmpeg.txt and licenses/LGPL-2.1.txt.
This software uses libraries from the FFmpeg project under LGPL 2.1 or later.
Source: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
Shared libavformat.so, libavcodec.so, libavutil.so and libswresample.so; no source patches.
GPL, nonfree, version3, network protocols and automatic external libraries disabled.
The matching source archive, signature and original build script are retained in
third_party/ffmpeg and scripts/build-ffmpeg.sh in the Evanna source repository.
Library replacement/re-signing instructions: docs/native-library-replacement.md.
The bounded local check decodes WAV/AIFF/FLAC/ALAC/MP3/AAC/Vorbis/Opus without playback.
libswresample is required internally by the native Opus decoder; Evanna's JNI
bridge does not resample decoded audio to a DAC rate. Lossy/floating PCM is
labelled as processed S32 with unknown original integer precision.

No online provider SDK, telemetry SDK, or cloud crash SDK is included.
