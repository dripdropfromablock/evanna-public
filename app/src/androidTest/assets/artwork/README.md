# Embedded cover fixtures

Original two-color PNG and blue JPEG generated by `scripts/generate-artwork-fixtures.py` with Python's standard library and host FFmpeg. Audio comes only from Evanna's existing original decoder fixtures. `cover-silence.flac` is two seconds of generated zero-valued PCM for the visible phone library; do not expose the signed-extrema decoder fixtures to physical playback.

FLAC/Ogg carry the PNG; MP3 deliberately carries the back JPEG before the front PNG; ALAC M4A carries JPEG. Expected extraction uses the independent image files and literal colors. Large/invalid APIC and PNG dimension-header cases are generated only in private test cache at runtime; no large padding asset is committed. SHA256SUMS records generated file identities. All fixtures live only in the separate test APK.
