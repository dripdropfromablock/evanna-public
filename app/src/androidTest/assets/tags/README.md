# Original album tag fixtures

Generated by `scripts/generate-tag-fixtures.py` using ffmpeg version 8.1.1-full_build-www.gyan.dev Copyright (c) 2000-2026 the FFmpeg developers.

Audio packets are copied from the existing decoder fixtures; metadata is original test data. `TagsProbe` checks tags without playback and compares decoded PCM to each source. FLAC/Vorbis carry a full date; MP4/ID3 may normalize dates/totals. Separate totals use FLAC comments; bounded.flac has a 5,000-byte composer. precedence.m4a adds a crafted track-level composer overriding the container composer without moving audio. The existing tagless stereo-16.wav is the empty-tags control.
