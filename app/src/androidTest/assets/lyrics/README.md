# Embedded lyrics fixtures

Generated by `scripts/generate-lyrics-fixtures.py` with host FFmpeg by stream-copying Evanna's own decoder fixtures; no new audio. `timed.m4a` carries MP4 `©lyr` LRC text, the form found in the user's library. `timed.flac` carries a Vorbis `LYRICS` comment with a header tag, an offset, a repeated stamp, a break and a word stamp. `plain.ogg` carries a stream-level `UNSYNCEDLYRICS` comment. `LyricsProbe` builds the MP3 ID3v2.4 `USLT` case at runtime and uses `decoder/stereo-16.wav` as the no-lyrics case. SHA256SUMS records file identities; the texts are repeated in `LyricsProbe.kt`. All fixtures live only in the separate test APK.
